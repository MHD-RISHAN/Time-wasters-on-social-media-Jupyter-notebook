# Time Wasters on Social Media – Data Analysis Using Pandas
Social media has become an integral part of daily life, but excessive usage often leads to significant time wastage and reduced productivity. This project, “Time Wasters on Social Media,” aims to analyze user behavior and identify patterns that contribute to inefficient time usage across different social media platforms. The analysis is performed using Python’s Pandas library within a Jupyter Notebook environment.
The primary goal of this project is to apply data analysis techniques to a real-world dataset and extract meaningful insights related to time consumption on social media. The project begins with data cleaning and preprocessing, where missing values, inconsistencies, and formatting issues are handled to ensure accurate analysis. Pandas functions are extensively used to manipulate, filter, and organize the data efficiently.
Following data preparation, Exploratory Data Analysis (EDA) is conducted to understand trends and usage patterns. This includes analyzing the amount of time spent on different platforms, identifying activities that consume the most time, and observing user engagement behavior. The project highlights which social media activities are most responsible for time wastage and how usage varies across different categories.
Basic data visualizations are used to present insights clearly and effectively, making the results easy to understand even for non-technical users. These visual representations help in comparing platforms, identifying peak usage trends, and summarizing key findings.
🔑 Key Insights
Identification of social media platforms that consume the most user time
Recognition of high time-wasting activities
Clear understanding of user engagement patterns
Practical insights into how social media usage impacts productivity

🎯 Purpose of the Project
This project was developed to strengthen practical skills in data analysis using Pandas, improve data-handling capabilities, and gain hands-on experience with real datasets. It also demonstrates the ability to derive actionable insights from raw data, which is a key requirement in data analytics roles.
This repository serves as a learning project and a foundation for more advanced data analysis and visualization work in the future.
